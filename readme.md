# Genith.ai  

Genith.ai is an AI Agent built using Generative AI that can **reason, plan, and act autonomously**.  
Inspired by the ReAct framework, Genith.ai combines the power of **LLMs, APIs, and Retrieval-Augmented Generation (RAG)** to create an assistant that doesn’t just chat — it thinks and executes.  

---

## 🚀 Project Vision  
Most AI tools today just answer questions. **Genith.ai** goes further: it can  
- Understand user intent through natural conversations  
- Fetch real-time data via APIs (e.g., weather, news, or tasks)  
- Retrieve personalized knowledge from a database using RAG  
- Reason step-by-step before responding (ReAct framework)  
- Take action: suggest plans, generate outputs, and even chain tasks together  

In short: **Genith.ai is your thinking + doing assistant.**  

---

## ✨ Core Features (Planned)  
1. **Conversational Agent** – Natural, context-aware chats powered by LLMs  
2. **Prompt Engineering Optimizations** – Role, Format, Tone, and Context (RFTC) based prompting  
3. **Function Calling** – Connect to external APIs (e.g., weather, calendar, search)  
4. **RAG Pipeline** – Store and retrieve context-specific data (like user notes or documents)  
5. **ReAct Agent** – Reason + Act loop for better decision-making  

---

## 🛠️ Tech Stack  
- **Frontend**: React (for interface)  
- **Backend**: Node.js / Express  
- **AI Model**: OpenAI GPT / LLaMA 3 (via API)  
- **Database**: Pinecone / Weaviate / Chroma (for vector storage in RAG)  
- **Frameworks**: LangChain / LlamaIndex  

---

## 📚 Example Use Cases  
- **Student Assistant**: Summarize lecture notes, create flashcards, answer queries  
- **Research Assistant**: Ingest PDFs, provide key insights, auto-generate references  
- **Personal Productivity**: Manage calendar, set reminders, fetch latest info
